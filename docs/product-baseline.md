# THE CAPITALIST 产品基准文档

版本：MVP v0.5  
日期：2026-08-09  
状态：Web 多场景原型已完成；Cocos/微信版本进入发布准备

## 1. 产品定位

THE CAPITALIST 是一款以“概率决策 + 风险管理 + 谈判选择”为核心的开箱博弈游戏。玩家选择一个私人箱子，逐轮淘汰其他箱子，观察剩余奖励的期望值（EV），在资本家报价与继续冒险之间做决定。

本产品的第一阶段目标是验证：

- 多场景电视节目式体验是否比单页面更有沉浸感。
- 玩家是否理解“打开箱子、淘汰金额、看报价、Deal / No Deal”的循环。
- 报价、还价、揭晓和结算是否形成可重复游玩的核心循环。

## 2. 产品边界

### MVP 必须包含

- 20 个箱子，随机分配 20 档奖励。
- 玩家先选择自己的私人箱子。
- 按轮次打开其他箱子并淘汰对应金额。
- 每个报价阶段显示剩余奖励和 EV。
- Capitalist 根据 EV、风险和进度生成报价。
- 玩家可选择 DEAL、COUNTER 或 HOLD / NO DEAL。
- Counter 支持玩家输入还价，Capitalist 可接受、拒绝或反报价。
- 最后揭晓私人箱子并显示结算评分。
- 有完整的页面转场、提示音、开箱音、淘汰音、报价音和结算音。

### 当前明确不做

- 不接真钱、充值、提现、现金奖励或可兑换高价值实物。
- 不接账号、数据库、玩家间 CAP/奖励交易。
- 不在 MVP 引入付费随机道具、盲盒售卖或博彩化宣传。
- 不以“稳赚、下注、投资回报、现金大奖”等表述对外推广。

## 3. 核心游戏规则

### 奖励池

20 档奖励：

`1、5、10、25、50、100、250、500、1,000、2,500、5,000、10,000、25,000、50,000、75,000、100,000、250,000、500,000、750,000、1,000,000 CAP`

CAP 仅是游戏内虚拟分数，不具备充值、提现、交易或现实货币价值。

### 轮次

每轮打开数量：`5 / 4 / 3 / 3 / 2 / 1`。

每轮结束后：

1. 计算剩余箱子的 EV。
2. Capitalist 生成本轮报价和台词。
3. 玩家选择 DEAL、COUNTER 或 HOLD / NO DEAL。
4. DEAL 进入最终揭晓；HOLD / NO DEAL 进入下一轮。
5. 最后一轮结束后自动进入最终揭晓。

### Counter 规则

- 玩家输入大于 0 的 CAP 报价。
- 低于接受线：Capitalist 接受并结束游戏。
- 处于谈判区间：Capitalist 提高报价并反报价，玩家可继续处理当前报价。
- 高于风险桌上限：Capitalist 拒绝还价，玩家仍可 DEAL、继续或重新还价。

## 4. 页面与转场基准

游戏不是单页面。每个状态都应该有独立的视觉重点、文案和音效。

| 页面 | 进入条件 | 主要内容 | 离开条件 |
| --- | --- | --- | --- |
| Lobby | 启动游戏 | 品牌、规则入口、Start | 点击 Start |
| Round Intro | 开始或进入新轮 | 大字号本轮指示、剩余数量、节奏提示 | 点击 Continue 或自动计时 |
| Board | 选择/打开箱子 | 20 个箱子、私人箱子顶栏、EV、进度 | 选完本轮数量 |
| Hostess Reveal | 玩家选中箱子 | 不同形象的礼仪小姐、开箱动画、金额揭晓 | 金额出现后自动转场 |
| Elimination | 金额揭晓后 | 全屏显示金额梯、刚淘汰金额高亮 | 点击 Continue 或自动计时 |
| Offer | 一轮结束 | 单独的 Capitalist、报价、EV、台词、Deal/No Deal | Deal、No Deal 或 Counter |
| Final Reveal | Deal 或最终轮结束 | 私人箱子开箱、实际金额、成交金额 | 自动进入 Result |
| Result | 游戏结算 | CAP、评分、🤡 或冠军庆祝、Restart | Restart |

### 转场要求

- 页面之间使用淡入、推入、缩放或镜头式转场，不能只替换同一块文字。
- Round Intro 的主提示使用本轮最大字号。
- 私人箱子选择后必须从箱子网格移动到顶部，成为独立的“Your Vault”。
- Offer 页面不显示箱子网格，突出 Capitalist 报价和决策按钮。
- 每次转场必须有短促的 original transition cue。

## 5. 角色与视觉资产

- Hostess：至少 6 个不同形象，按轮次轮换；负责开箱和金额揭晓。
- Capitalist：至少 6 个不同形象，按报价轮次轮换；报价页面只保留人物、报价、EV 和操作区。
- 视觉方向：黑色舞台、金色聚光灯、白色金额牌、红色风险提示，保持电视节目式层次。
- 使用原创角色和原创音效，不直接复制第三方游戏的品牌、角色、美术、台词或音乐。
- 图标优先使用现有图标库；按钮图标和文字同时表达 DEAL、COUNTER、HOLD 等动作。

## 6. 音效基准

当前 MVP 使用 Web Audio 生成的原创合成音，后续可替换为经过授权的音频资源。

| Cue | 使用时机 | 目标感觉 |
| --- | --- | --- |
| transition | 页面切换 | 短、清晰、带舞台感 |
| round | 本轮指示 | 激情、明确、提高期待 |
| select | 选择箱子 | 确认私人选择 |
| reveal | 开箱金额出现 | 上升后落点 |
| eliminate | 金额被淘汰 | 低沉、清楚、不可误解 |
| offerPrompt | Capitalist 报价 | 紧张、聚焦 |
| deal | DEAL | 结束风险、确认成交 |
| noDeal | NO DEAL / HOLD | 延续风险、推进下一轮 |
| finalReveal | 私人箱子揭晓 | 悬念释放 |
| champion | 高于或等于箱内金额的胜利结算 | 庆祝、胜者感 |
| clown | 低于箱内金额的结算 | 轻喜剧、缓慢出现 |

## 7. 结算与评分

- DEAL：玩家获得成交报价。
- COUNTER 接受：玩家获得最终接受的还价。
- HOLD / 最终揭晓：玩家获得私人箱子中的 CAP。
- 若玩家获得的 CAP 小于私人箱子金额，结果页逐渐出现 🤡 捏鼻子动画。
- 若玩家获得的 CAP 大于或等于私人箱子金额，结果页展示冠军庆祝画面，并使用原创 champion cue；“We are the champion my friend”只作为后续授权音乐方向，不能在未获授权时直接使用原曲录音。

## 8. 平台基准

| 平台 | 当前定位 | 技术路线 | 当前状态 |
| --- | --- | --- | --- |
| Web | 玩法和视觉验证 | React + TypeScript + Vite | 已有可玩多场景版本 |
| 微信小游戏 | 中国大陆优先的游戏入口 | Cocos Creator 3.8.8 -> 微信小游戏 | 工程骨架已存在，待工具/AppID |
| 微信小程序 | 若需要非游戏业务壳或活动页 | 原生小程序/小游戏跳转 | 未开始，需先确定入口形态 |
| 抖音小游戏 | 后续区域版本 | Cocos Creator -> 抖音小游戏 | 待平台适配 |
| iOS/Android | 后续独立 App | Cocos Creator 原生构建 | 待资源和账号准备 |

本项目优先按“微信小游戏”处理，因为核心体验是全屏互动游戏。若要提交的是“微信小程序”，需要额外确定是把游戏作为小程序主体，还是做一个活动/内容小程序再跳转小游戏。

## 9. 扩展接口

已保留以下适配边界，但 MVP 不实现真实服务：

- Account adapter：账号、游客身份、存档。
- Share card adapter：分享卡、战绩卡、邀请链接。
- Skin adapter：非交易型角色和舞台皮肤。
- Virtual currency adapter：仅用于未来合规评审后的虚拟 CAP 体系。
- Platform adapter：Web、Cocos、微信、抖音的音频、分享、支付和生命周期差异。

任何支付、广告、虚拟商品、随机道具和社交交易功能都必须单独做合规评审、概率披露、未成年人保护和平台审核准备。

## 10. 验收标准

- 从 Lobby 到 Result 可以完整走通，不需要刷新页面。
- 选择私人箱子后，箱子在视觉上移动并固定在顶部。
- 每一轮选择结束后先进入 Hostess Reveal，再进入 Elimination，再进入 Offer。
- Offer 页面没有箱子网格，只展示报价决策。
- Deal、No Deal、Counter 三条路径都能完成或继续游戏。
- 最终揭晓能区分成交金额和私人箱子真实金额。
- 输赢结果分别触发 🤡 或冠军状态，且页面转场和音效不会重复叠加。
- Web、Cocos 共用 `packages/core` 的奖励、轮次、EV、报价和结算规则。
- 不存在真钱、提现、交易或现实奖励入口。
