# 微信小游戏部署清单

## 当前结论

仓库内已有 Cocos Creator 3.8.8 工程骨架：

`apps/cocos/the-capitalist-cocos`

它可以被 Cocos Creator 导入，并且包含共享核心规则、主场景和基础控制脚本；但当前仓库没有微信小游戏 AppID，也没有已生成的微信发布目录，因此现在不能诚实地宣称“已上传微信平台”。

## 发布前必须具备

1. Cocos Creator 3.8.x，建议使用工程声明的 3.8.8。
2. 微信开发者工具，并完成登录。
3. 微信公众平台的小游戏 AppID 和对应开发者权限。
4. 小游戏名称、头像、简介、类目、隐私指引和用户协议。
5. 已确认的竖屏/横屏方向、首包大小策略和资源加载策略。

## 本地构建流程

1. 在仓库根目录执行 `npm install`。
2. 执行 `npm run sync:cocos-core`，把 `packages/core` 同步到 Cocos 工程。
3. 用 Cocos Creator 打开 `apps/cocos/the-capitalist-cocos`。
4. 打开 `assets/Main.scene`，确认场景可以预览。
5. 在构建发布面板选择微信小游戏平台，填入小游戏 AppID。
6. 选择构建目录，例如 `build/wechatgame`，执行构建。
7. 在微信开发者工具中导入构建目录，填写同一个 AppID。
8. 在模拟器和真机上测试启动、音效、页面转场、返回前后台和横竖屏表现。
9. 修复平台日志中的资源路径、音频自动播放、分包和包体问题后，再上传体验版。

## 首次上传前验收

- 不需要登录即可开始一局。
- 不调用真钱支付、提现、现金奖励或玩家间交易。
- 首次用户手势后再播放音频，避免平台自动播放限制。
- 切后台、回前台、锁屏、弱网和重启不会卡在半个场景。
- 私人箱子、淘汰金额、报价和最终结算的文本在小屏设备不重叠。
- 随机奖励、EV、报价和结算仍由共享核心规则计算。
- 没有未授权的第三方音乐、角色、品牌或宣传语。

## 目前的阻塞项

- 未检测到可直接调用的 Cocos Creator CLI 或微信开发者工具命令。
- 未提供微信小游戏 AppID。
- 尚未确认微信公众平台主体、开发者权限和类目。
- 当前 Cocos 工程仍是基础场景骨架，需要在 Creator 中绑定和调整移动端视觉资源。

## 交付给开发者的最小信息

请提供或在本机准备：

- 微信小游戏 AppID。
- 已登录微信开发者工具。
- Cocos Creator 3.8.8 的安装位置。
- 目标方向：微信小游戏，或“微信小程序壳 + 小游戏”。

拿到这些条件后，才能继续完成真实的微信构建、导入、预览和上传体验版；仅凭现有 Web 地址不能直接转换成合规的微信小游戏发布包。
